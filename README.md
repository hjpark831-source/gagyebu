# 가계부

갤럭시 폰에서 쓰는 나만의 가계부 웹앱이에요. 깃허브 페이지에 올려 두고, 폰 브라우저에서 '홈 화면에 추가'해 앱처럼 씁니다.

## 지금 되는 것

- 빠른 입력: 금액을 누르고 분류를 누르면 바로 저장
- 홈: 이번 달 남은 예산, 수입·고정지출·변동지출 합계, 최근 기록
- 가계부: 수입 / 고정지출 / 변동지출로 나눠 보기, 목록·달력 보기, 기록 고치기·삭제
- 고정지출 자동 기록: 통신비, 보험료처럼 매달 나가는 돈을 결제일에 자동으로 기록
- 통계: 분류별 소비, 지난달과 비교, 적금·주식은 따로 표시
- 설정: 월 예산, 분류 추가·이름 바꾸기·순서·삭제, 엑셀(CSV) 내려받기

기록은 지금 폰 브라우저 안에만 저장돼요. 구글 계정 자동 백업(Firebase)과 자산 탭은 다음 단계에서 붙입니다.

## 폰에 설치하기

1. 저장소 **Settings → Pages**에서 Source를 **GitHub Actions**로 둡니다.
2. 코드가 올라가면 Actions 탭에서 배포가 끝날 때까지 기다립니다 (1~2분).
3. 갤럭시의 크롬이나 삼성 인터넷에서 `https://hjpark831-source.github.io/gagyebu/` 를 엽니다.
4. 메뉴에서 **홈 화면에 추가**를 누릅니다.

## 개발

```bash
npm install
npm run dev
```
